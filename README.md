# Wave — Chat with Friends

Pure client-side chat + rooms + mini-games app.

## Current Status

The repository currently has a **placeholder** `index.html`.

The **complete working version** was created in our conversation.  
To make the site fully functional:

1. Copy the full upgraded `index.html` from the chat (the long one I provided earlier).
2. In this repo click on `index.html` → pencil icon (Edit this file).
3. Replace everything with the full code → Commit changes.
4. Enable GitHub Pages:
   - Go to **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` / Folder: `/ (root)`
   - Save

Your live site will be:
**https://kab6767767676767-boop.github.io/wave-chat/**

## Does it work offline?

**Yes.**  
Once the page is loaded (or you save the HTML file and open it locally), the entire app works without internet.  
All accounts, messages, contacts, rooms and game scores are stored in the browser’s `localStorage`.

## Features
- Sign in / Sign up (local only)
- Contacts & People discovery
- Group rooms with shareable 6-character codes
- Messaging
- Local video-call demo (your camera)
- 4 mini-games + leaderboards
